# AutoDock Vina {#autodock-vina}

AutoDock Vina searches a specified space for possible receptor–ligand poses and scores them. It is a docking engine with PDBQT inputs. See the [Vina manual](https://vina.scripps.edu/manual/).

## Where does Vina fit in the workflow? {#vina-在整个流程中处于什么位置}

```text
Input structures → chemical processing / preparation → receptor and ligand PDBQT
                                                               ↓
                                                              Vina
                                                               ↓
                                                        docking results
```

Vina performs the docking search after the inputs have been prepared.

## What does Vina search? {#vina-在搜索什么}

It explores ligand position, orientation and permitted torsions. A flexible-receptor task also searches specified receptor side chains. Inputs and box coordinates define the task.

## Is Vina the same as AutoDock 4? {#vina-和-autodock-4-一样吗}

They are related docking engines with different algorithms and scoring functions. Shared formats do not make their calculations equivalent.

## Does Vina require AutoGrid4? {#vina-需要-autogrid4-吗}

Ordinary Vina scoring computes its required grids internally. With `ad4` scoring, Vina instead reads affinity maps generated by AutoGrid4. See the [official basic docking tutorial](https://github.com/ccsb-scripps/AutoDock-Vina/blob/develop/docs/source/docking_basic.rst).

## In DockStart {#在-dockstart-中}

DockStart organizes the workflow; Vina executes the docking calculation. They operate at different levels of the software stack.
